使用与维护说明

第一次使用，先看「使用说明」了解两台打印机怎么选；负责维护系统，直接看「维护说明」。

四步完成打印

  1. 1
    打开系统

    电脑浏览器访问打印站网址；手机连接同一 WiFi 后扫码打开。

  2. 2
    上传文件

    拖拽或点击选择文件，支持图片、PDF、Word、Excel、PPT、文本，可一次传多个。

  3. 3
    预览并设置

    点「预览」确认内容；在顶部选打印机，在文件卡片上设置份数和黑白/彩色。

  4. 4
    打印并取纸

    点「打印」，等任务状态变成「已完成」后到打印机取纸。

使用须知

先预览，再打印

打印前确认页数、方向和内容无误。页面比纸张大时，缩放默认「适当缩小」，可避免只印出左上角。

双面需要手动翻面并点「继续」

两台设备都没有自动双面，需要手动完成：第一面打印完后，把纸按正确方向翻面放回纸盘，再到打印站电脑（运行本系统、连接打印机的那台）的打印机窗口点「继续」，才会打印第二面。只翻纸不点「继续」，任务会一直停着。

「等待打印机」不是失败

打印机休眠、缺纸或离线时任务会显示等待。先去打印机按一下唤醒键或补纸，任务会继续，不要重复提交。

文件会自动删除

上传的文件约 30 分钟后自动清理，打印完请及时取走纸质文件。

格式与大小

支持图片、PDF、Word、Excel、PPT、文本，单个文件最大 100 MB。

手机打印

手机需连接与打印站相同的 WiFi；预览建议使用 Chrome 或 Edge 浏览器。

打错了怎么取消？

网页上的「打印任务」只显示进度，没有取消按钮。发现打错后不要反复点打印，请尽快按下面步骤取消：

  1. 先在打印机面板按「取消 / 停止」键（如果有），阻止它继续出纸。
  2. 到打印站电脑（运行本系统、连接打印机的那台）打开打印队列：双击任务栏右下角的打印机图标； 或按 Win + R 输入 control printers 回车，再双击对应打印机。
  3. 在队列里找到刚提交的文档，右键 →「取消」。彩色打印机有两个名称，一个队列里找不到时，检查另一个名称的队列。
  4. 如果队列里已经没有任务、打印机还在出纸：这些页面已经送进打印机内存，按打印机面板的取消键； 仍停不下来时，可先按电源键关闭打印机，在打印站电脑清空队列后再开机。

若自己无法操作打印站电脑，请找负责维护的同学处理；不要直接拔电源线或反复提交任务。

常见问题

选了「彩色」，打出来还是黑白？

大概率是选了 HP LaserJet 1020，它只能打印黑白。需要彩色时请把顶部「打印机」切换为 HP Color LaserJet Pro MFP M176 的两个名称之一，并在文件卡片上选择「彩色」。

双面只打了一面，或停在中间不动？

这两台打印机都没有自动双面。第一面打完后，需要把纸按正确方向翻面放回纸盘，然后到打印站电脑（运行本系统、连接打印机的那台）的打印机队列或驱动提示窗口点「继续」，第二面才会继续打印。只翻纸不点「继续」，任务会一直停着。若没有出现提示，可以改用「更多设置 → 页码范围」分两次打印奇偶页。

在网页上能取消打印吗？

不能。网页上的「打印任务」只显示进度，没有取消按钮。请按上方「打错了怎么取消」的步骤，到打印站电脑的对应打印机队列里取消；彩色打印机两个名称的队列都要看一下。

任务一直显示「等待打印机」怎么办？

检查打印机是否休眠、缺纸、卡纸或离线。软件无法自动唤醒休眠的 USB 打印机，请到打印机上按一下唤醒键；处理后任务会自动继续。若长时间没有变化，再重新提交。

设置多份，但只出了一份？

先看 Windows 打印机队列里是否还有未完成的任务。若队列卡住，清理队列后重新提交，并留意任务状态是否变为「已完成」。

预览空白，或手机上打不开预览？

优先使用 Chrome 或 Edge；部分手机浏览器会下载 PDF 而不是直接显示，可在新标签页打开预览链接查看。

打印出来文字特别大，或每页只有左上角一块？

通常是 PDF 页面尺寸远大于 A4。请在「更多设置 → 缩放」中选择「适当缩小」或「铺满页面」，不要用「原始大小」。

接手前先确认
  • 系统必须运行在连接打印机的那台 Windows 电脑上，不能部署到 Linux / Mac。
  • 该电脑需安装 Microsoft Office，Word / Excel / PPT 转 PDF 依赖它。
  • 服务要跑在已登录的桌面会话里，不要注册成无人值守服务，否则 Office 转换会失败。
  • 打印引擎 vendor/SumatraPDF.exe 必须存在，缺失时无法打印。

部署与启动

源码运行

  1. 安装 Python 3.10+（安装时勾选 Add to PATH）。
  2. 双击 install.bat，自动安装依赖并下载 SumatraPDF。
  3. 双击 start.bat 启动，窗口会显示访问网址和二维码。

打包 exe（推荐长期部署）

  1. pip install -r requirements.txt pyinstaller
  2. python download_sumatra.py
  3. python build.py，产物为 dist\PrintTools.exe

开机自启

python install_autostart.py --target "C:\路径\PrintTools.exe"
:: 取消自启
python install_autostart.py --uninstall

采用「登录后从启动文件夹运行」，保证有桌面会话，Office COM 才能正常转换。

常用配置

项目位置 / 变量说明
登录开关与账号 config.ini 的 [auth] 源码运行时在项目根目录，打包后在 exe 同目录；改动后重启生效。默认 enabled = false。
重置登录密码 python -m app.auth 源码运行时执行，把生成的 pbkdf2_sha256$... 粘贴到 password = 后面。
服务端口 PRINT_TOOLS_PORT 默认 8000；被占用时改成其他端口。
文件保留时长 PRINT_TOOLS_RETENTION 默认 30 分钟，超时自动清理上传文件。
上传大小上限 PRINT_TOOLS_MAX_MB 默认 100 MB。
打印引擎路径 SUMATRA_PATH 默认 vendor/SumatraPDF.exe。

环境变量优先级高于 config.ini。真实密码不要写进仓库，也不要写在本页。

常见故障速查

现象排查方向
Office 文档转换失败 确认已安装 Microsoft Office；确认服务运行在已登录的桌面会话中，而不是无人值守服务。
点打印没有反应 检查 vendor/SumatraPDF.exe 是否存在；确认打印机已连接、在线，并能打印测试页。
多份只出一份 程序通过多次调用打印实现份数，先检查 Windows 打印机队列是否卡住，清理后重试。
双面打印停在第一面 属于手动双面流程：把纸翻面放回纸盘后，需在打印站电脑的打印机队列或驱动提示窗口点「继续」；若没有出现提示，改为单面 + 页码范围分两次打印。
任务取消不掉 / 打印机一直出纸 网页端没有取消按钮。到打印站电脑打开对应打印机队列（M176 两个名称都要检查）→ 右键任务「取消」；队列为空仍出纸时，按打印机面板取消键，必要时重启 Print Spooler 服务（会取消所有人的任务）。
文字超大 / 只印出左上角 PDF 页面尺寸大于纸张。让用户把缩放改为「适当缩小」或「铺满页面」。
一直显示「等待打印机」 多为打印机休眠、缺纸、卡纸或离线。软件无法自动唤醒休眠的 USB 打印机；可在打印机设置里调长睡眠时间或关闭自动关机。
预览空白 / 手机不显示 建议使用 Chrome 或 Edge；部分手机浏览器会下载 PDF，可改为在新标签页打开预览链接。
启动失败 / 端口被占用 关闭占用端口的程序，或通过 PRINT_TOOLS_PORT 改用其他端口。

更新与交接清单

  1. 从仓库拉取最新代码：git pull。
  2. 依赖有变化时重新执行 install.bat；使用 exe 部署则重新执行 python build.py。
  3. 重启服务后，用黑白、彩色、双面（翻面后点「继续」）、多份各打印一张测试页。
  4. 不要向仓库提交 config.ini、uploads/ 和用户上传的文件。
  5. 设备增减、名称变化或要求变化时，直接修改本页 web/illustrate.html 中的设备卡片。
  6. 交接时确认：打印站电脑、Office 授权、打印机驱动、SumatraPDF、GitHub 仓库权限。
